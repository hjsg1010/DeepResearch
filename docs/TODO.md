## 기술 부채

### 개선 필요 사항

1. **타입 힌트 완성**: 일부 함수의 타입 힌트 누락
2. **docstring 보완**: 일부 내부 메서드의 문서화
3. **예외 처리 개선**: 더 구체적인 예외 클래스 사용
4. **테스트 커버리지**: 80% 이상으로 확대
5. **코드 정리**: 중복 코드 제거, 리팩토링
